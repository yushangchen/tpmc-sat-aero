# TPMC-Sat-Aero

TPMC-Sat-Aero is a Python-based Test Particle Monte Carlo solver for estimating aerodynamic coefficients of satellites, CubeSats, and deorbit drag-sail configurations in rarefied orbital flow conditions.

The code is designed for rapid aerodynamic coefficient mapping in the free-molecular and high-Knudsen-number regimes. It tracks incident test particles, models gas-surface momentum exchange, and computes aerodynamic force and moment coefficients for arbitrary triangulated geometries.

This project is intended to support preliminary satellite deorbit analysis and future comparison with Direct Simulation Monte Carlo (DSMC) reference simulations.
